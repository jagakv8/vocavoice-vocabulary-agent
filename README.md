# VocaVoice – Vocabulary Learning Voice Agent

## Overview
VocaVoice is a browser-based voice agent designed to help users improve their English vocabulary through interactive learning, speech recognition, pronunciation and quizzes.

## Features
- Text-to-speech pronunciation.
- Voice-based interaction.
- Vocabulary explanations.
- Example sentences.
- Interactive multiple-choice quizzes.
- Score tracking.
- Beginner-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Speech API
- Speech Recognition API

## How to Run
1. Clone this repository.
2. Open `index.html` in Google Chrome.
3. Allow microphone access.
4. Click Listen or Speak with Coach.
5. Start learning vocabulary!

## Future Improvements
